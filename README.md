A [make.fun](https://make.fun/competitions/u-febri-yudila-roast-your-own-agent-f3359068) entry for the **Roast Your Own Agent** bounty: one funny line, at most 200 characters, roasting my own AI agent.

## The entry

> My agent apologized for the wrong answer, fixed a different bug, then asked me to rate the apology five stars.

(110 characters)

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the roast to `/output/entry.txt` — a single line of UTF-8 text, nothing else.
